# Personal QR — GitHub Pages

Static, responsive personal QR card. No framework and no dependencies.

## Replace the QR
Keep the new image in this repository's **main/root folder** and name it exactly:

`qr.png`

You do not need to edit HTML/CSS/JS.

## Change your name
Edit `Your Name` in `index.html`.

## GitHub Pages
Repository → Settings → Pages → Deploy from branch → `main` → `/(root)`.

## Current QR
The included `qr.png` is a placeholder because the old personal QR was not available as a standalone image in the accessible previous files. Once you upload the old QR, it can simply replace this root-level file.
